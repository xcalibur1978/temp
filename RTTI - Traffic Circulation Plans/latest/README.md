# RTTI — Traffic Circulation Plans

This folder contains the published deliverables of the model **RTTI — Traffic Circulation Plans** (version **0.1.0**), generated and published from Ontologica.

## What's in here?

The content is organized by **version**. At version level you'll find the README and the language-neutral `RDF's/` folder; every language (including the default) has its own `<lang>/` subfolder with the language-specific deliverables. The following files may be present (depending on what was included in this publication):

- **`RDF's/`** — the machine-readable RDF serializations of the model (Turtle `.ttl`, RDF/XML `.rdf`, JSON-LD `.jsonld`). Language-neutral: the RDF contains all languages at once.
- **`<lang>/index.html`** — the readable specification as a ReSpec page (open in a browser). One per language, each in its own `<lang>/` subfolder. GitHub Pages serves each `index.html` as the folder's index.
- **`<lang>/*.pdf`** — the same model as a PDF document. One per language, in that language's subfolder.
