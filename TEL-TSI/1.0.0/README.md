# TEL-TSI

This folder contains the published deliverables of the model **TEL-TSI** (version **1.0.0**), generated and published from Ontologica.

## What's in here?

The content is organized by **version** and by **language**. Per language the following files may be present (depending on what was included in this publication):

- **`RDF's/`** — the machine-readable RDF serializations of the model (Turtle `.ttl`, RDF/XML `.rdf`, JSON-LD `.jsonld`). Language-neutral: the RDF contains all languages at once.
- **`*.html`** — the readable specification as a ReSpec page (open in a browser). One per language.
- **`*.pdf`** — the same model as a PDF document. One per language.

## Folder structure

```
TEL-TSI/

        TEL-TSI_<LANG>_v1.0.0.jsonld
      TEL-TSI_<LANG>_v1.0.0.html   (if ReSpec is included)
      TEL-TSI_<LANG>_v1.0.0.pdf    (if PDF is included)
```
