# DATEXII conceptual model

Deze map bevat de gepubliceerde deliverables van het model **DATEXII conceptual model**
(versie **0.0.0**), gegenereerd en gepubliceerd vanuit Ontologica.

## Wat vind je hier?

De inhoud is geordend per **versie** en per **taal**. Per taal kunnen de
volgende bestanden aanwezig zijn (afhankelijk van wat bij deze publicatie is
meegegeven):

- **`RDF's/`** — de machineleesbare RDF-serialisaties van het model
  (Turtle `.ttl`, RDF/XML `.rdf`, JSON-LD `.jsonld`). Taal-neutraal: de RDF
  bevat alle talen tegelijk.
- **`*.html`** — de leesbare specificatie als ReSpec-pagina (open in een
  browser). Eén per taal.
- **`*.pdf`** — hetzelfde model als PDF-document. Eén per taal.
