# NAPCORE Core Concepts

This folder contains the published deliverables of the model **NAPCORE Core Concepts** (version **0.0.0**), generated and published from Ontologica.

## What's in here?

The content is organized by **version**. The **default language** is the main version and lives directly in the version folder; every other language has its own subfolder. The following files may be present (depending on what was included in this publication):

- **`RDF's/`** — the machine-readable RDF serializations of the model (Turtle `.ttl`, RDF/XML `.rdf`, JSON-LD `.jsonld`). Language-neutral: the RDF contains all languages at once.
- **`index.html`** — the readable specification as a ReSpec page (open in a browser). The default language is in the version folder; each other language in its own `.../{lang}/` subfolder. GitHub Pages serves each `index.html` as the folder's index.
- **`*.pdf`** — the same model as a PDF document. One per language (default language in the version folder, others in their subfolder).

## Folder structure

```
NAPCORE Core Concepts/
  0.0.0/
    README.md                            (this file)
    index.html                           (default language, if ReSpec is included)
    NAPCORE Core Concepts_EN_v0.0.0.pdf  (if PDF is included)
    RDF's/                               (if RDF is included)
      NAPCORE Core Concepts_v0.0.0.ttl
      NAPCORE Core Concepts_v0.0.0.rdf
      NAPCORE Core Concepts_v0.0.0.jsonld
    <lang>/                              (one per other language, e.g. BG, CS, DA, DE, EL, EN, ES, ET, FI, FR, GA, HR, HU, IT, LT, LV, MT, NL, PL, PT, RO, SK, SL, SV)
      index.html                         (if ReSpec is included)
      NAPCORE Core Concepts_<LANG>_v0.0.0.pdf      (if PDF is included)
```
