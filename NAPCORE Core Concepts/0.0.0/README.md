# NAPCORE Core Concepts

This folder contains the published deliverables of the model **NAPCORE Core Concepts** (version **0.0.0**), generated and published from Ontologica.

## What's in here?

The content is organized by **version** and by **language**. Per language the following files may be present (depending on what was included in this publication):

- **`RDF's/`** — the machine-readable RDF serializations of the model (Turtle `.ttl`, RDF/XML `.rdf`, JSON-LD `.jsonld`). Language-neutral: the RDF contains all languages at once.
- **`*.html`** — the readable specification as a ReSpec page (open in a browser). One per language.
- **`*.pdf`** — the same model as a PDF document. One per language.

## Folder structure

```
NAPCORE Core Concepts/
  0.0.0/

    RDF's/                 (if RDF is included)
      NAPCORE Core Concepts_v0.0.0.ttl
      NAPCORE Core Concepts_v0.0.0.rdf

    <LANG>/                (e.g. BG, CS, DA, DE, EL, EN, ES, ET, FI, FR, GA, HR, HU, IT, LT, LV, MT, NL, PL, PT, RO, SK, SL, SV)
      NAPCORE Core Concepts_<LANG>_v0.0.0.html   (if ReSpec is included)
      NAPCORE Core Concepts_<LANG>_v0.0.0.pdf    (if PDF is included)
```
