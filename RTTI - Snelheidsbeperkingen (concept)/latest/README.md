# RTTI - Snelheidsbeperkingen (concept)

Deze map bevat de gepubliceerde deliverables van het model **RTTI - Snelheidsbeperkingen (concept)** (versie **0.0.1**), gegenereerd en gepubliceerd vanuit Ontologica.

## Wat vind je hier?

De inhoud is geordend per **versie**. Op versie-niveau vind je de README en de taal-neutrale map `RDF's/`; elke taal (ook de standaardtaal) heeft een eigen `<taal>/`-submap met de taal-specifieke deliverables. De volgende bestanden kunnen aanwezig zijn (afhankelijk van wat bij deze publicatie is meegegeven):

- **`RDF's/`** — de machineleesbare RDF-serialisaties van het model (Turtle `.ttl`, RDF/XML `.rdf`, JSON-LD `.jsonld`). Taal-neutraal: de RDF bevat alle talen tegelijk.
- **`<taal>/index.html`** — de leesbare specificatie als ReSpec-pagina (open in een browser). Eén per taal, elk in een eigen `<taal>/`-submap. GitHub Pages serveert elke `index.html` als de index van die map.
- **`<taal>/*.pdf`** — hetzelfde model als PDF-document. Eén per taal, in de submap van die taal.
